# discord-wap-kaios
A simple KaiOS hosted app for @gtrxAC's [Discord WAP client](https://github.com/gtrxAC/discord-wap).

**NOTE:** You will need to have [Wallace Toolbox](https://gitlab.com/suborg/wallace-toolbox) installed in order to install this app.

## Initial setup

1. Download the [latest discord-wap-kaios release](https://github.com/klte-hype/discord-wap-kaios/releases/latest/).
2. Open the ``discord-wap-kaios-vX.X.X.zip`` file on a PC.
3. Open the manifest.webapp file found inside of the ``application.zip`` file.
4. Change the ``"start_url"`` field to the URL of your Discord WAP server (default value is ``"start_url": "http://wap.gtrxac.fi/"``).
5. Save the file.

## How to use
See the "How to use" section of the [Discord WAP](https://github.com/gtrxAC/discord-wap) project page to get more information.
