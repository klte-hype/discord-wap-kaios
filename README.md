# discord-wap-kaios
A simple hosted app for @gtrxAC's [Discord WAP client](https://github.com/gtrxAC/discord-wap) on KaiOS devices.

**NOTE:** You will need to have [Wallace Toolbox](https://gitlab.com/suborg/wallace-toolbox) installed in order to install this app.

## Initial setup

1. Open the discord-wap-kaios.zip file on a PC.
2. Open the manifest.webapp file inside the application.zip file.
3. Change the ``"start_url"`` field to the URL of your Discord WAP server (by default it's ``"start_url": "https://wap.gtrxac.fi/"``).
4. Save the file.

## How to use
See the [Discord WAP](https://github.com/gtrxAC/discord-wap) project page to get more information.
